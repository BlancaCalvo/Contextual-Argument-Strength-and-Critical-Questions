# Contextual-Argument-Strength-and-Critical-Questions

This repository contains the data, the generation details, and the app for the paper "Do Critical Questions Improve Argument Evaluation? An Experimental Study".

This includes a dataset of arguments built to study how critical questions affect people's ability to judge argument strength, and to support future work on argument evaluation more broadly in folder **`dataset/`** . And the scripts to build such dataset in **`data_generation/`** .

The app deployed to gather the user data in **`app/`** , and the data obtained in the study in **`output/`** .
